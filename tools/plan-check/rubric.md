## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| Diagnosis | The plan’s explanation and the reproduction evidence | The plan explains what caused the problem, and the reproduction evidence supports that explanation. | required |
| Scope | The proposed changes and the issue description | The proposed changes stay focused on fixing the issue and avoid unrelated work. | required |
| Test plan | The planned test and the reproduction steps | The plan says how to repeat the test and what result would show the fix worked. | required |
| Plan comment | Candidate plan comment, Thread highlights, and Repo facts | The comment follows any relevant requests in the issue thread and any contribution rules that apply to the proposed work. | required |


## Verdict rule

Accept only if every required check passes. If any required check fails or is unclear, reject the plan.
