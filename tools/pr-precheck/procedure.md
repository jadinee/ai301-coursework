# Procedure

## Read order

Identify the mode. For live mode, check scope before reading the issue and thread, repo rules, plan, diff, test evidence, and PR draft. Read the voice guide for live feedback. For eval mode, read the supplied bundle end to end. Read the rubric and evidence guide before grading.

## Evidence gathering

Compare the plan and its Deviations with each diff hunk and the issue's scope. Compare the test plan with the recorded commands and results, and compare the PR's claims and checked boxes with that evidence. Compare the title, summary, and changes with the diff. Compare the draft and diff with the applicable repo rules and thread requests. Record a quote or fact for each comparison.

## Check execution

Use the rubric in table order. Mark each pass, fail, or unclear and cite the deciding evidence in one line. Identify missing required evidence explicitly. In live mode, distinguish checkout errors or inaccessible inputs from omissions in a readable draft. Record voice issues separately.

## Verdict assembly

Apply the rubric's verdict rule to all checks. Give the readable per-check summary and finish with the exact JSON format in the starter contract.
